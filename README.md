**1st-Line-Tech_Support_onboarding**

Веб-платформа для онбординга новых сотрудников первой линии технической поддержки САО «ВСК»: интерактивная книга-руководство, тестирование с защитой от списывания и панель руководителя отдела.

**О проекте**

Дипломный проект — корпоративная система онлайн-обучения для новых специалистов первой линии поддержки. Платформа позволяет сотруднику самостоятельно изучить учебный материал в формате интерактивной книги, пройти итоговое тестирование и получить отметку о прохождении курса. Руководитель отдела видит результаты тестов, количество попыток и сводный статус «сдал / не сдал».

**Возможности**

- 📖 Интерактивная книга-руководство
- Учебный материал в виде книги с постраничной навигацией
- Специально подготовленная вёрстка страниц под «книжный» формат
- Листание страниц прямо в браузере
- Зум и скроллинг изображений
- Удобное оглавление и переход к нужному разделу

**Тестирование с защитой от списывания**

- Случайная генерация вопросов из заранее заготовленного пула
- При обновлении страницы прогресс не сбрасывается
- Таймер не останавливается при перезагрузке
- Кнопки «Проверить ответы» и «Выйти»
- Автоматическая фиксация результата после завершения

**Панель руководителя отдела**

- Просмотр результатов тестов сотрудников
- Отображение количества попыток
- Сводный результат: сдал / не сдал
- Страница ведущего специалиста с общей статистикой

**Стек**

- JavaScript — основная логика (книга, тест, таймер, навигация)
- HTML / CSS — разметка и оформление страниц
- PHP — серверная часть, работа с данными и результатами тестов
- Shell — вспомогательные скрипты

**Идея**
Курс решает проблему длительного и трудозатратного обучения новых сотрудников: ведущие специалисты тратят время на стажёров вместо работы с запросами. Платформа позволяет новичкам проходить обучение самостоятельно, а руководителю — контролировать прогресс и качество усвоения материала без постоянного вовлечения в процесс.
